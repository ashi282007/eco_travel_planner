# 🌱 EcoRoute – Eco Travel Guide

A Flask web application that helps travellers make more sustainable travel choices. Users can compare routes, calculate the CO₂ of a trip, check how sustainable a destination is, and see overtourism and water-scarcity alerts.

> **Note:** the datasets in this project are **synthetic** (generated by the Python scripts in this repository) and are used to demonstrate how the application works. They are not real measurements.

## Features

| Feature | Description |
|---|---|
| Eco route finder | Compares a popular route with an eco route (distance, traffic, fuel and CO₂ saved) |
| Carbon calculator | CO₂ for a trip by vehicle type and number of passengers, plus a "trees to offset" estimate |
| Destination score | Sustainability score based on waste management, crowding, air quality and eco-hotels |
| Alerts | Overtourism and water-scarcity warnings per destination |
| City transport finder | Metro, EV stations, bicycle rental and bus frequency per city |
| Emission chart | Chart of emissions by vehicle type |
| Eco checklist and quiz | Interactive sustainability score and quiz |
| PDF report | Downloadable "Eco Readiness" report |
| Accounts | Sign-up and login with hashed passwords |
| City autocomplete | Search suggestions while typing |

## Tech stack

- **Backend:** Python, Flask, Jinja2
- **Database:** SQLite (`eco_data.db`)
- **Frontend:** HTML, CSS, JavaScript
- **Other:** ReportLab (PDF), pandas (data generation)

## How to run

```bash
pip install flask reportlab pandas
python app.py
```

Then open http://127.0.0.1:5000 in your browser. The database (`eco_data.db`) is included.

## Project structure

| Path | Purpose |
|---|---|
| `app.py` | Flask application and all routes |
| `templates/` | HTML pages (Jinja2) with a shared `layout.html` |
| `static/` | CSS, JavaScript and images |
| `eco_data.db` | SQLite database |
| `generate_routes.py`, `generate_city_transport.py`, `generat_all_csv.py` | Scripts that generate the synthetic datasets |
| `init_db.py` | Creates the base tables |

## Known limitations

- All environmental data is synthetic.
- Only the generated source–destination pairs are available in the route finder.
- The CO₂ model is simplified; the electric-vehicle value is a placeholder.
